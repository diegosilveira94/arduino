# Sistemas Embarcados

Projetos da disciplina de Sistemas Embarcados com Arduino Uno R3.

**Alunos:** Diego Silveira e Gustavo Moraes

## Projetos

| Pasta | Descrição |
| --- | --- |
| `giroflex/` | Giroflex com 4 LEDs e sirene no buzzer |
| `sensorDeRe/` | Sensor ultrassônico de ré com indicador RGB e buzzer que acelera os bipes conforme o obstáculo se aproxima |
| `ventilador/` | Servo com movimento oscilante para simular um ventilador; entradas analógicas controlam o ângulo e a velocidade |

## Como rodar

1. Instale a [IDE do Arduino](https://www.arduino.cc/en/software).
2. Abra o arquivo `.ino` da pasta do projeto.
3. Em **Ferramentas > Placa**, selecione **Arduino Uno**.
4. Em **Ferramentas > Porta**, selecione a porta da placa.
5. Clique em **Carregar**.

Cada projeto fica na própria pasta, com o mesmo nome do arquivo `.ino`.
